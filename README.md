# Consumer EEG BCI — Attention Detection

> **EEG-based Brain-Computer Interface** that detects **focused vs. relaxed** mental states in real time using affordable consumer-grade EEG headsets. Trained on the SEED-VIG dataset with Leave-One-Subject-Out cross-validation.

---

## Architecture

```
Raw 5-channel EEG (200Hz)
        ↓
 ┌──────────────┐
 │     SEN      │  ← Signal Enhancement Network (U-Net denoiser)
 │  (denoiser)  │     Cleans cheap headset noise
 └──────┬───────┘
        ↓
 ┌──────────────────────────┐
 │  EEGNet → BiLSTM → Attn │  ← Classifier
 │     (CNN-LSTM)           │     Focused (0) vs Relaxed (1)
 └──────────────────────────┘
        ↓
    {Focused, Relaxed}
```

**Model:** ~268K parameters | **Input:** (batch, 5 channels, 400 samples) | **Output:** binary class

**5 channels:** Fp1, Fpz, Fp2, Fz, FC1 — works with consumer 4-5 electrode headsets

## Setup on a New Machine

### 1. Clone the repo

```bash
git clone https://github.com/aniskabachar/Consumer-EEG-BCI.git
cd Consumer-EEG-BCI
```

### 2. Create a virtual environment

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

> **GPU (recommended):** Go to https://pytorch.org/get-started/locally/ and install the CUDA version.
> Example for CUDA 12.1:
> ```bash
> pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
> ```

### 4. Download the SEED-VIG Raw Data

The raw EEG `.mat` files (~2.8 GB total) are NOT in this repo. Download them manually:

1. Go to: https://bcmi.sjtu.edu.cn/home/seed/seed-vig.html
2. Register and download the dataset
3. Place the 23 `.mat` files into:

```
SEED-VIG/Raw_Data/
├── 1_20151124_noon_2.mat
├── 2_20151106_noon.mat
├── ...  (23 files)
```

> The `SEED-VIG/perclos_labels/` folder is already in the repo — do NOT move or re-download it.

### 5. Run the pipeline

**Step 1 — Preprocess** (generates the 1.1 GB .npz, takes ~5–15 min):
```bash
python main.py preprocess --data_dir ./SEED-VIG --output_dir ./processed_data
```

**Step 2 — Train** (LOSO cross-validation, 23 folds):
```bash
python main.py train \
  --data_path ./processed_data/seed_vig_5ch_processed.npz \
  --save_dir ./processed_data/saved_models \
  --epochs 80 \
  --batch_size 64
```

Quick test (1 fold only):
```bash
python main.py train --data_path ./processed_data/seed_vig_5ch_processed.npz --max_folds 1
```

**Step 3 — Evaluate:**
```bash
python main.py evaluate \
  --data_path ./processed_data/seed_vig_5ch_processed.npz \
  --models_dir ./processed_data/saved_models
```

**Step 4 — Real-time demo:**
```bash
python main.py demo --model ./processed_data/saved_models/fold_1_subject_0.pth
```

## Preprocessing Pipeline

```
Raw EEG (200 Hz, 17 channels)
  → Bandpass filter  0.5–45 Hz
  → Notch filter     50 Hz + 60 Hz
  → Epoch            2s windows, 50% overlap  → (400 samples, 17 ch)
  → Z-score normalize  (per channel, per epoch)
  → Select 5 channels  [FP1, FPZ, FP2, FZ, FC1]
  → Label  PERCLOS > 0.5 → Drowsy(1), else Alert(0)
```
